# Tabs Component Color Variation

An independent prototype based on the existing UMD Design System
`umd-element-tabs` component.

## State treatment

- Selected tab label: `#000000`
- Unselected tab labels: `#757575`
- Active indicator: unchanged from the Design System
- Component interaction and content switching: unchanged

## Preview

Serve the repository root and open:

`http://127.0.0.1:8010/tabs-component-color-variation/`

The project-specific variation is isolated in `styles.css`. No Design System
source files are modified.
